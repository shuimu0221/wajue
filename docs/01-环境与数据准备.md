## 2. RDKit 版本是硬约束

评测页原文：

> Both your SMILES and the answer are passed through RDKit's tautomer canonicalization
> (**pinned at 2026.03.3**) and reduced to the first block of their InChIKey.

```bash
python -m pip install "rdkit==2026.3.3"
python -c "import rdkit; print(rdkit.__version__)"
```

装完把版本号写进 `experiments.md`。

**如果 pip 上拿不到精确的 2026.03.3**：不要凑一个近似版本。走这条路——

1. 在 Kaggle Notebook 里（官方镜像就是判分版本）算一次全量
   `raw_ik14 → metric_key` 映射和候选池；
2. 落盘成 Dataset 下载回来；
3. **本地永远不重算 metric key**。

`train.parquet` 自带 `inchikey14` 列可以直接拿来做初筛，
但**它与评测 key 的差异量级未知**（上一版草稿里写的 "1.58% / 4,370 个" 是我编的，
已删除）。W1 第一天用 Kaggle 镜像实测一次，把真实差异率记进 `experiments.md`。

## 3. 数据下载

```bash
# 1) 先去 https://www.kaggle.com/settings → API → Create New Token 下载 kaggle.json
# 2) 放到 ~/.kaggle/kaggle.json
mkdir -p ~/.kaggle && cp kaggle.json ~/.kaggle/ && chmod 600 ~/.kaggle/kaggle.json

# 3) 接受比赛规则（浏览器里点一次），否则下载 403
#    https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/rules

# 4) 下载
cd data/raw
kaggle competitions download -c enveda-CASMI26-molecule-id-mass-spectra
unzip -o enveda-CASMI26-molecule-id-mass-spectra.zip
```

预期拿到三个文件：

| 文件 | 大小量级 |
|---|---|
| `train.parquet` | ~2.5M 行 × 18 列，**可能数 GB** |
| `test.parquet` | ~1,500 行 × 12 列，小 |
| `sample_submission.csv` | 小 |

> ⚠️ **`test.parquet` 是训练集的样本**，不是真测试集。见 docs/00 §2。

## 4. 下载后立刻做的三件事

```bash
cd wajue
# 1) 数据能不能读通 + schema 对不对
python code/a_load.py --stats

# 2) 亲手确认「可见 test 来自 train」这件事（不要只信文档）
python code/a_load.py --check-leak

# 3) 提交格式与评测自检
python code/a_submit.py --selftest
python code/a_eval.py --selftest
```

第 2 步的输出会打印 `fingerprint_overlap_frac`。如果接近 1.0，
**任何在可见 test 上算出来的分数都不能用**。
