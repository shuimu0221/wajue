## 常见错误

| ❌ | ✅ |
|---|---|
| 直接相加原始概率 | 分子内 rank 归一化（已实现） |
| 前向模型对 2000 候选全算 | 只算 top-100 |
| 在公开榜上搜融合权重 | OOF 上搜 |
| 排序优化吃掉召回 | 每次看 `recall@25`，掉了就是在牺牲兜底 |
| 留一堆无贡献特征 | W1 删一半 |
| 降级链没测过 | 每档跑 `--smoke` |
