### 四通道

| 通道 | 做法 | 注意 |
|---|---|---|
| `f_cos` | 余弦，强度 **sqrt** 变换 | 峰容差按 Da（timsTOF 常用 0.01） |
| `f_entropy` | 谱熵相似度（`ms_entropy`） | 先统一前处理 |
| `f_nl` | **中性丢失**：`precursor_mz − fragment_mz` | 对同系物（±CH2）极有效，class 2 主力 |
| `f_analog` | `max over 近邻(cos³ × Tanimoto(候选, 近邻))` | **用 max 不用 sum**；近邻 top-20 |
| `f_lib_hit` | 是否存在近似参考谱（0/1） | 供 ranker 区分有无谱证据 |

**关键：加合物感知**。测试集用 **10 种**加合物（`common.TEST_ADDUCTS`）：

```
[M+H]+  [M+NH4]+  [M-H2O+H]+  [M-2H2O+H]+  [M+Na]+
[M+K]+  [M-H]-    [M-H2O-H]-  [M+CH2O2-H]-  [M+Cl]-
```

跨加合物做 analog 匹配前，先用 `common.neutral_mass_from_precursor()` 校正到中性质量，
否则同系物匹配不上。**注意测试集没有二聚体**，不要针对它优化。

### 官方推荐的前处理（原文列的清单，直接用）

1. 相对强度下限（2% / 1% / 0.1%）
2. 丢掉高于母离子的峰（+1–2 Da 容差）
3. 最少峰数 ~5–6
4. 最大峰数 top-128；**经典变体：每 50 Da 窗口 top-6**
5. 去同位素峰（+1.0033 Da 的 C13 伴峰）
6. 强度 sqrt / log 变换

## 常见错误

| ❌ | ✅ |
|---|---|
| 验证时按来源库过滤 | 按 `cand_key` 排除 + 断言 |
| analog 用 sum 聚合 | 用 max |
| 生成时不卡分子式 | 分子式与精确质量不符的一律丢（白占位置） |
| 生成候选压过检索结果 | 只往尾部插 |
| 在公开榜上挑近邻数 | 只在 `mimic` 折上比 |
| 针对二聚体优化 | 测试集只有 10 种加合物，无二聚体 |
