## 0. 三条铁律

1. **每人只写自己的文件。** 想改别人的函数 → 提 issue，不要直接改。
2. **主流程只加开关，不加分支。** `run_pipeline.py` 里用 `--use-fp false`，不要写 `if 张三的模型...`。
3. **中间产物落盘为 parquet，主键固定。** 内存里传 DataFrame 只用于同进程调试。

## 1. 核心标识符

| 名字 | 定义 | 谁生成 |
|---|---|---|
| `molecule_id` | 赛题给的匿名 ID，**预测单位** | 原始数据 |
| `spectrum_id` | 谱唯一 ID | 原始数据 |
| `cand_key` | **候选唯一键 = InChIKey14**（tautomer 规范化后） | A |
| `fold` | 交叉验证折号 | A |

**`cand_key` 必须等于评测 key。** 全队最重要的一条约定：候选池去重、特征表 join、
提交去重，全部用同一个 key。**不要用 SMILES 字符串当键。**

`train.parquet` 自带的 `inchikey14` 列**可以直接当 `cand_key` 的初值**，
但要注意它未必是 tautomer 规范化后的版本（评测 pin 在 RDKit 2026.03.3）。
**第一次建库时用 A 的 `ik14_map` 统一重算一次并缓存**，之后一律用缓存。

## 2. 数据结构

### 2.1 原始 schema（官方，照抄）

`test.parquet` — 12 列：

```
molecule_id, spectrum_id, ms2_mzs, ms2_normalized_intensities,
base_peak_intensity, adduct, ionization_mode, instrument_type,
precursor_mz, collision_energy_ev, collision_energy_orig, collision_energy_orig_units
```

`train.parquet` — 上述 12 列 + 8 列：

```
normalized_smiles, inchikey, inchikey14, molecular_formula,
ingest_lib, adduct_orig, precursor_error_ppm, num_peaks
```

**必须知道的几点**：
- `ms2_mzs` / `ms2_normalized_intensities` 是**成对齐数组**，基峰 = 1.0
- `collision_energy_ev` 是 **list**，`[20]` 单次、`[20,40,60,80]` 多次合并
- 模型要吃碰撞能就用 `collision_energy_ev`（官方指定这一列与测试集对齐）
- `ionization_mode` 是**字符串** `positive` / `negative`

### 2.2 `data/interim/spectra.parquet` ← A 产出（`a_load.load_split`）

| 列 | 类型 | 说明 |
|---|---|---|

| `spectrum_id` | string | |

| `base_peak_intensity` | float32 | |

## 4. 提交文件契约（官方原文）

```
molecule_id,smiles
m_0014ef,CC1=CC(=O)C=CC1=O;OC(=O)c1ccccc1O;CN1C=NC2=C1C(=O)N(C)C(=O)N2C
m_004d06,NCCc1ccc(O)cc1;CC(=O)Nc1ccc(O)cc1;OCC(O)CO
```

`validate_sub` 必须覆盖官方全部拒收条件：

1. 缺 `molecule_id` 或 `smiles` 列
2. 文件为空
3. 任一列含 null
4. `molecule_id` 重复
5. 任一分子超过 25 个分号分隔的猜测

另加我们自己的检查：

6. 同一行内 `cand_key` 无重复（第二个永远拿不到分，还白占一格）
7. 每个 SMILES 能被 RDKit 解析

**每次提交前必跑，并记录到 `experiments.md`。**

## 5. 三条工程纪律

1. **特征表按通道各写各的文件。** 不要两人同时写 `features/all.parquet`。
2. **候选池变更是 breaking change。** 重建必须通知全队，并在 `experiments.md` 记
   `candidates.parquet` 的行数 + hash（`a_candidates.candidates_hash()`）。
3. **每人 W1 结束时必须能跑通**：
   ```bash
   python code/run_pipeline.py --stage all --smoke
   ```
   只取 50 个分子，5 分钟内跑完。
